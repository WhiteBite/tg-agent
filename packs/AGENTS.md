# packs/ — реестр декларативных паков извлечения

Извлечение сущностей из переписки описано декларативно: движок `extract.py`
generic, а предметная область живёт в паке. Пакет задаёт, какие виды сущностей
искать, каким промптом и в каком окне, и как их дедуплицировать.

Сейчас два пака: `construction` (`decision/task/promise/question`) и `services`
(`service/trial/promo`).

## Контракт

Пак — `dict`, проверяемый валидатором `_validate` в `packs/__init__.py` при импорте:

| Поле | Тип | Смысл |
|---|---|---|
| `id` | `str` | идентификатор пака |
| `version` | `int` | версия |
| `kinds` | `dict` | непустой словарь видов сущностей |
| `prompt_template` | `str` | промпт; обязан содержать `{scope_header}`, `{messages}`, `{open_entities}` |
| `ops` | `list` | подмножество `new / update / close / reopen / start / block / unblock` |
| `json_schema` | `dict` | схема ответа; `enum` операции (`properties.ops.items.properties.op.enum`) обязан совпадать с `ops` |
| `backfill_days` | `int` | окно первого прогона |
| `field_policies` | `dict` | политики полей |

Дополнительно пак может нести:

- `scope_filter` — где он вообще запускается: `require_match` (нужен непустой
  проект) и `exclude_project_regex` (например, `^сервисы$`, чтобы констракшн не
  лез в сервисные темы);
- `dedup_scope` — область дедупа (`project` или `global`);
- ключ дедупа `dedup_hint` (домен/слаг сервиса): строки с одним хинтом
  схлопываются в одну сущность.

## Инварианты

- **Evidence обязателен.** Каждая операция несёт цитаты (`minItems: 1`); цитата —
  подстрока текста сохранённого сообщения (плюс транскрипты медиа), иначе операция
  отклоняется, причина — в `extraction_runs.rejects_json`.
- Валидатор пакета падает на импорте при нарушении контракта — пак нельзя
  «подключить наполовину».
- Схему и промпт держи согласованными: `enum` в `json_schema` и список `ops`
  обязаны совпадать, иначе импорт упадёт.
- `TG_EXTRA_PACKS=<путь к .py>` — сторонний файл со словарём `PACKS`: паки
  добавляются поверх встроенных с той же валидацией. Не задан — ничего не
  происходит; сбой загрузки не роняет импорт реестра, а уходит в
  `packs.EXTRA_ERROR` (`{"ok": false, "error": …}`).

Новый пак — скилл `add-pack`. Семантику проверяет `tests_packs_semantics.py`.
